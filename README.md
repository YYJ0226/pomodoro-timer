# 🍅 番茄钟应用

一个简洁美观的桌面番茄钟应用，帮助你提高专注力和工作效率。

## 功能特点

- ⏱️ **计时功能**：默认工作25分钟，休息5分钟
- 🎨 **美观界面**：工作/休息模式有不同颜色主题
- 🔔 **声音提醒**：计时结束播放提示音
- 📢 **系统通知**：桌面通知提醒你切换状态
- 📊 **统计功能**：记录完成的番茄数
- ⚙️ **自定义设置**：可调整工作和休息时间

## 使用方法

### 方法1：双击运行
双击 `启动番茄钟.bat` 文件即可启动

### 方法2：命令行运行
```bash
cd ~/pomodoro-timer
python pomodoro.py
```

## 操作说明

1. 点击 **开始** 按钮开始计时
2. 点击 **暂停** 可以暂停计时
3. 点击 **重置** 可以重新开始当前计时
4. 点击 **工作/休息** 可以手动切换模式
5. 在底部设置区域可以调整时间

## 番茄工作法

1. 选择一个要完成的任务
2. 设定25分钟工作时间
3. 专注工作直到计时结束
4. 短暂休息5分钟
5. 每4个番茄后，休息15-30分钟
