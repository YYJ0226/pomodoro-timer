# 🍅 番茄钟应用

一个简洁美观的桌面番茄钟应用，帮助你提高专注力和工作效率。

运行环境：Windows、Python 3.11 或更新版本（含 Tkinter）。提示音使用 Windows 的 `winsound`，目前不宣称支持 Linux/macOS。除可选系统通知外，无需安装第三方包。

## 功能特点

- ⏱️ **计时功能**：默认工作25分钟，休息5分钟
- 🎨 **美观界面**：工作/休息模式有不同颜色主题
- 🔔 **声音提醒**：计时结束播放提示音
- 📢 **系统通知**：桌面通知提醒你切换状态
- 📊 **统计功能**：记录完成的番茄数
- ⚙️ **自定义设置**：工作 1–60 分钟、休息 1–30 分钟；输入错误时保留原设置和计时状态

## 使用方法

### 方法1：双击运行

双击 `启动番茄钟.bat` 文件即可启动

### 方法2：命令行运行

在项目所在目录打开终端：

```powershell
python pomodoro.py
```

如需可选系统通知，可在同一个 Python 环境运行 `python -m pip install plyer`；不安装也可使用计时器。系统通知和提示音需在真实桌面单独检查。

## 操作说明

1. 点击 **开始** 按钮开始计时
2. 点击 **暂停** 可以暂停计时
3. 点击 **重置** 可以重新开始当前计时
4. 点击 **工作/休息** 可以手动切换模式
5. 在底部设置区域可以调整时间

输入要求：使用半角数字；允许首尾空格和前导零，例如 `025`。不接受空值、0、负数、越界值、小数、正号、下划线或全角数字。两个输入都合法才会一起应用；应用成功会停止并重置当前模式的计时，不会清零已完成计数。

测试直接调用真实的设置、重置和进度更新方法，只替换 Tk 控件与消息框，不打开窗口、不等待真实倒计时，也不发通知。GitHub Actions 在 Windows / Python 3.11、3.13 上执行相同检查；这不是完整桌面验收或计时准确性验证。

本阶段记录见 [P1 输入校验验收](docs/p1-settings-validation.md)，包括修复前后的复现命令、提交和手工检查清单。

## 番茄工作法

1. 选择一个要完成的任务
2. 设定25分钟工作时间
3. 专注工作直到计时结束
4. 短暂休息5分钟
5. 每4个番茄后，休息15-30分钟

以上为方法说明；当前应用仅自动切换工作／短休息，并未实现每四次自动长休息。完成计数仅保存在本次运行内，关闭后不保留。计时线程及持久化改进属于后续阶段，不在本次输入校验修复中。
